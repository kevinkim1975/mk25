# 병원 맞춤 영업 랜딩페이지 PRD

## 1. 프로젝트 개요
- **제품 이름(가칭)**: Ad-Recovery Landing Page
- **목적**: 네이버 키워드 광고 예산이 오전에 소진되어 오후에는 노출이 끊기는 병원의 문제를 진단·해결 방법을 제시하고, 상담(견적) 신청 리드를 확보한다.
- **플랫폼**: Web (반응형, 모바일 퍼스트)

## 2. 목표 & 성공 지표
| 분류 | KPI | 목표치 |
|------|-----|--------|
| 전환 | 상담 폼 제출 건수 | 월 30건 |
| 효율 | 폼 전환율(유입 대비) | ≥ 15% |

## 3. 타깃 사용자
| 속성 | 내용 |
|------|------|
| 업종 | 병원, 의원, 치과 등 의료기관 |
| 직무 | 원장(의사) 또는 마케팅 담당자 |
| 상황 | 네이버 키워드 광고를 집행 중이나 예산 소진이 빨라 오후 노출이 끊김 |
| 핵심 고민 | “광고 예산이 부족한 걸까?” “왜 오전에만 노출되고 환자 문의가 줄어들까?” |
| 사용 디바이스 | 모바일 > PC |

## 4. 핵심 문제(페인 포인트)
“광고 예산이 오전에 소진되어 오후엔 노출이 끊기는 문제로 신규 환자 유입이 감소한다.”

## 5. 주요 기능(FEATURES)
| 순서 | 섹션 | 상세 내용 |
|------|------|-----------|
| 1 | Hero | 헤드라인 “지금 이 순간, 당신의 광고는 꺼져 있습니다” + 서브카피 + 대표 이미지/배경 영상 |
| 2 | 문제 제기 | 해당 병원의 오전 10시 vs 오후 2시 광고 노출 스크린샷 맞춤 삽입 |
| 3 | 원인 분석 | 예산 소진 구조·낭비 요인 설명 텍스트 블록 |
| 4 | 해결 전략 | 3–4개 아이콘 카드(캠페인 분류, 순위 전략, 노출 시간 전략, 확장 검색 효율화) |
| 5 | 결과 증명 | 실제 데이터 그래프 + 애니메이션(“같은 예산, 3배 노출”) |
| 6 | 리드 캡처 폼 | 필드: 병원명, 담당자명, 연락처, 상담요청내용. 제출 시 Google Sheets 저장, 카카오톡 알림, 성공 메시지 & CTA 반복 |

## 6. 비범위(OUT OF SCOPE)
- 실시간 채팅, 일정 예약, PDF 다운로드 기능
- 복수 언어 지원
- 백오피스 관리 페이지

## 7. 사용자 플로우
1. 직접 URL 방문(우편·DM 링크)
2. Hero → 문제 제기 이미지 확인
3. 원인 분석 텍스트 읽기
4. 해결 전략으로 해결 가능성 인식
5. 결과 증명 그래프 애니메이션 통해 확신 획득
6. 리드 캡처 폼 작성·제출
7. 성공 메시지 확인, 상담 대기

## 8. 기술 스택 & 아키텍처
- Frontend: Next.js 15 (SSG) + TypeScript + TailwindCSS + shadcn/ui + Lucide Icons
- State & Data: Google Sheets(폼 응답 + 콘텐츠 데이터)
- Notification: KakaoTalk 나에게 보내기 API (폼 제출 시 알림)
- Media: Cloudinary 이미지 최적화
- 배포: Vercel(Preview → Production)
- 애니메이션: Framer Motion (그래프), date-fns (날짜 처리)

## 9. 제약사항 & 가정
- 병원별 맞춤 URL 생성 시 빌드 파이프라인에서 Google Sheets → static paths로 변환
- 개인정보(연락처) 수집 시 구글 폼/Sheets API로 SSL 전송
- 의료법 광고 규제 준수(효과 과장 금지)
