# Ad-Recovery Landing Page Design Guide

## 1. 전체적인 무드 (Overall Mood)

이 서비스는 병원의 네이버 광고 예산 소진 문제를 해결하는 전문적인 B2B 솔루션으로, **신뢰성과 전문성**을 바탕으로 한 차분하고 안정감 있는 디자인 무드를 추구합니다. 의료진과 마케팅 담당자들이 느끼는 광고 성과에 대한 불안감을 해소하고, 데이터 기반의 명확한 해결책을 제시하는 **신뢰할 수 있는 파트너**의 이미지를 구축합니다.

핵심 키워드: **Professional, Trustworthy, Data-driven, Solution-focused**

## 2. 참조 서비스 (Reference Service)

- **Name**: 호원앤컴퍼니 (Howon & Company)
- **URL**: https://howoncompany.co.kr/
- **Description**: 기업용 디지털 마케팅 솔루션 제공 서비스
- **Design Mood**: 깔끔하고 전문적인 기업용 서비스 톤앤매너, 신뢰감을 주는 차분한 색상과 명확한 정보 전달
- **Primary Color**: #0A2540 (Deep Navy)
- **Secondary Color**: #1D5FD4 (Bright Blue)

## 3. 색상 & 그라데이션 (Color & Gradient)

- **Primary Color**: #0A2540 (Deep Navy) - 메인 텍스트, 헤딩, 중요 요소
- **Secondary Color**: #1D5FD4 (Bright Blue) - CTA 버튼, 포인트 컬러, 그래프 하이라이트
- **Accent Color**: #19C2A1 (Mint Green) - 성과 지표, 긍정적 데이터 표현 (소량 사용)
- **Background**: #FFFFFF (White) / #F5F7FA (Light Gray)
- **Text Color**: #333333 (Dark Gray)
- **Border/Divider**: #E1E6EF (Cool Gray)
- **Error Color**: #E53E3E (Red)

**Mood**: Cool 톤의 차분한 색상 조합으로 높은 신뢰도 구현
**Color Usage**: 
- Primary (Deep Navy): 헤딩, 중요 텍스트, 아이콘
- Secondary (Bright Blue): CTA 버튼, 링크, 데이터 포인트
- Accent (Mint Green): 성과 개선 지표, 긍정적 변화 표현
- Neutral: 본문 텍스트, 배경, 구분선

## 4. 타이포그래피 & 폰트 (Typography & Font)

- **Primary Font**: Pretendard (한국어 최적화, 웹 안전 폰트)
- **Heading 1**: Pretendard SemiBold, 48px (3rem), Line-height 1.2
- **Heading 2**: Pretendard SemiBold, 36px (2.25rem), Line-height 1.3
- **Heading 3**: Pretendard SemiBold, 24px (1.5rem), Line-height 1.4
- **Body Large**: Pretendard Regular, 18px (1.125rem), Line-height 1.6
- **Body**: Pretendard Regular, 16px (1rem), Line-height 1.6
- **Caption**: Pretendard Regular, 14px (0.875rem), Line-height 1.5
- **Button Text**: Pretendard Medium, 16px (1rem), Letter-spacing -0.01em

**특징**: 
- 가독성 우선의 적절한 행간 설정
- 의료 전문 용어의 명확한 전달을 위한 충분한 글자 크기
- 모바일에서의 가독성을 고려한 최소 16px 본문 크기

## 5. 레이아웃 & 구조 (Layout & Structure)

**그리드 시스템**:
- 최대 컨텐츠 폭: 1200px
- 12컬럼 그리드 시스템
- 좌우 패딩: 24px (모바일), 48px (태블릿), 80px (데스크탑)
- 컬럼 간격: 24px

**섹션 간격**:
- 데스크탑: 96px
- 태블릿: 80px  
- 모바일: 64px

**레이아웃 원칙**:
- 단일 컬럼 중심의 스토리텔링 구조
- 시각적 위계를 통한 정보 전달 순서 명확화
- 모바일 퍼스트 반응형 설계
- 스크롤 기반의 자연스러운 정보 흐름

## 6. 비주얼 스타일 (Visual Style)

**아이콘**:
- 스타일: Lucide Icons 라인 아이콘
- 두께: 1.5px stroke
- 크기: 24px (기본), 32px (강조), 48px (대형 섹션)
- 색상: Primary Navy 기본, 포인트 시 Bright Blue

**이미지**:
- 스크린샷: 960×540px PNG, 병원명 워터마크
- 그래프/차트: 데이터 시각화 중심의 깔끔한 디자인
- 카드 섀도우: 0 4px 12px rgba(0,0,0,0.05)

**일러스트레이션**:
- 최소한의 장식적 요소
- 데이터와 정보 전달에 집중
- 의료업계 특성을 고려한 전문적 톤앤매너

## 7. UX 가이드 (UX Guide)

**타겟 사용자**: 병원 원장 및 마케팅 담당자 (전문가 그룹)

**핵심 UX 원칙**:

1. **명확한 정보 전달**: 복잡한 광고 구조를 쉽게 이해할 수 있도록 단계별 설명
2. **신뢰성 구축**: 실제 데이터와 사례를 통한 신뢰도 향상
3. **즉시성**: 문제 인식부터 해결책 제시까지 빠른 정보 전달
4. **전문성**: 의료업계 특성을 고려한 전문적 어조와 정확한 용어 사용

**인터랙션 가이드**:
- 전문 용어에 대한 Tooltip 제공 (🛈 아이콘)
- 단계별 스크롤 가이드 제공
- 모바일 환경에서의 터치 최적화
- 최소 클릭 원칙으로 정보 즉시 노출

**접근성**:
- WCAG AA 준수 (4.5:1 이상 대비율)
- 키보드 네비게이션 지원
- 명확한 포커스 표시
- 스크린 리더 호환성

## 8. UI 컴포넌트 가이드 (UI Component Guide)

### 버튼 (Buttons)
**Primary Button**:
- 배경: #1D5FD4 (Bright Blue)
- 텍스트: #FFFFFF (White)
- 패딩: 16px 32px
- 보더 라디우스: 8px
- 호버: scale(1.05), shadow-lg
- 트랜지션: 150ms ease

**Secondary Button**:
- 배경: transparent
- 텍스트: #1D5FD4 (Bright Blue)
- 보더: 2px solid #1D5FD4
- 패딩: 14px 30px
- 호버: 배경 #1D5FD4, 텍스트 #FFFFFF

### 입력 필드 (Input Fields)
- 보더: 1px solid #E1E6EF
- 패딩: 12px 16px
- 보더 라디우스: 6px
- 포커스: 보더 #1D5FD4, shadow 0 0 0 3px rgba(29,95,212,0.1)
- 라벨: 필드 상단, Pretendard Medium 14px
- 에러 상태: 보더 #E53E3E, 에러 메시지 빨간색

### 카드 (Cards)
- 배경: #FFFFFF
- 보더 라디우스: 12px
- 섀도우: 0 4px 12px rgba(0,0,0,0.05)
- 패딩: 24px
- 호버: 배경 rgba(25,194,161,0.05), 섀도우 증가

### 네비게이션 (Navigation)
**Top Navigation**:
- 고정 위치, 배경 #FFFFFF, 하단 보더 #E1E6EF
- 로고: 좌측 정렬
- 앵커 링크: 우측 정렬, Pretendard Medium 16px
- 모바일: 햄버거 메뉴 + Drawer

**Floating Action Button (FAB)**:
- 위치: 우측 하단 고정
- 크기: 56px × 56px
- 배경: #1D5FD4
- 아이콘: 흰색 전화 아이콘
- 섀도우: 0 4px 16px rgba(29,95,212,0.3)

### 툴팁 (Tooltips)
- 배경: #333333
- 텍스트: #FFFFFF
- 패딩: 8px 12px
- 보더 라디우스: 4px
- 최대 폭: 200px
- 트리거: 🛈 아이콘 호버

### 그래프/차트 (Charts)
- 메인 컬러: #1D5FD4
- 그리드: #E1E6EF
- 애니메이션: 1.2초 EaseOut
- 데이터 포인트: 원형, 8px 지름
- 호버 상태: 확대 및 값 표시

### 모달/팝업 (Modals)
- 오버레이: rgba(0,0,0,0.5)
- 배경: #FFFFFF
- 보더 라디우스: 16px
- 최대 폭: 600px
- 패딩: 32px
- 닫기 버튼: 우상단, X 아이콘

이 디자인 가이드는 병원 맞춤 영업 랜딩페이지의 전문성과 신뢰성을 강화하여 타겟 사용자들의 전환율을 극대화하는 것을 목표로 합니다.
