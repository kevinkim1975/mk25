# User Journey – 병원 맞춤 영업 랜딩페이지

## 페르소나
"김지은" 35세, 치과 마케팅 팀장
- 아침마다 네이버 광고 대시보드를 확인하지만 예산이 10시 전에 소진됨
- 팀 예산·성과 압박으로 새로운 솔루션을 탐색 중
- 기술 지식은 평균, 모바일로 자료를 자주 확인

---

## 단계별 여정

1. 인지(Direct Outreach)
   - 영업팀으로부터 DM/우편으로 랜딩 URL 수신
   - 휴대폰으로 QR 스캔하여 페이지 오픈

2. 관심(Hero)
   - 헤드라인 “지금 이 순간, 당신의 광고는 꺼져 있습니다”에 즉시 공감
   - CTA 버튼 “내 광고 상태 확인하기”를 스크롤 유도

3. 문제 확인(Problem Section)
   - 오전 10시 vs 오후 2시 스크린샷을 보고 자신의 상황과 동일함을 인지
   - 호기심 증가, 더 읽기로 이동

4. 원인 이해(Cause Analysis)
   - ‘예산이 아니라 구조가 문제’라는 문구에 고개 끄덕임
   - 지출 구조 도식화 이미지를 5초간 주시

5. 해결책 탐색(Solution Strategy)
   - 4개의 카드(캠페인 분류, 순위 전략 등)를 빠르게 훑어봄
   - ‘우리도 간단히 적용 가능하겠다’는 기대 형성

6. 신뢰 확보(Result Evidence)
   - 그래프 애니메이션으로 “같은 예산 3배 노출” 데이터 확인
- 실제 성과 지표 표를 보고 전환 의지 강화

7. 행동(Lead Capture Form)
   - 병원명, 담당자명, 연락처, 상담내용 입력 후 ‘상담 신청’ 클릭
   - 성공 메시지 “30분 내 컨설턴트가 연락드릴게요” 확인

8. 애프터 행동
   - 메신저로 성공 스크린샷 팀에 공유
   - 30분 내 컨설턴트 전화 수신 → 상담 진행
