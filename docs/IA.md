# Ad-Recovery Landing Page 정보 아키텍처 (IA)

## 1. 사이트맵 (사이트맵)

```
Ad-Recovery Landing Page
├── 메인 페이지 (/)
│   ├── Hero 섹션 (#hero)
│   ├── 문제 제기 섹션 (#problem)
│   ├── 원인 분석 섹션 (#cause)
│   ├── 해결책 섹션 (#solution)
│   ├── 결과 증명 섹션 (#result)
│   └── 리드 캡처 폼 섹션 (#lead)
├── 성공 페이지 (/success)
├── 개인정보 처리방침 (/privacy)
└── 이용약관 (/terms)
```

## 2. 사용자 흐름 (사용자 흐름)

**주요 작업: 상담 신청 완료**
1. 사용자가 DM/우편 링크를 통해 랜딩페이지 접속
2. Hero 섹션에서 헤드라인 확인 후 "상담 신청하기" CTA 클릭 또는 스크롤
3. 문제 제기 섹션에서 병원별 맞춤 스크린샷 확인
4. 원인 분석 섹션에서 광고 구조 문제점 인지
5. 해결책 섹션에서 4가지 전략 카드 탐색
6. 결과 증명 섹션에서 그래프 애니메이션 시청
7. 리드 캡처 폼 작성 (병원명, 담당자명, 연락처, 상담내용)
8. "상담 신청" 버튼 클릭
9. 성공 페이지로 리다이렉트, 30분 내 연락 안내 확인

**보조 흐름: 정보 탐색**
1. 네비게이션 앵커 링크를 통한 특정 섹션 이동
2. 툴팁 아이콘 호버로 전문 용어 설명 확인
3. 플로팅 "다음으로" 버튼으로 순차적 섹션 이동

## 3. 네비게이션 구조 (네비게이션 구조)

**상단 네비게이션 (Global Navigation)**
- 로고 (좌측)
- 앵커 링크 메뉴 (우측)
  - 문제 확인 (#problem)
  - 해결 방법 (#solution)  
  - 성과 증명 (#result)
  - 상담 신청 (#lead)
- CTA 버튼: "상담 신청하기" (#lead)

**모바일 네비게이션**
- 햄버거 메뉴 (Drawer)
  - 문제 확인
  - 해결 방법
  - 성과 증명
  - 상담 신청
- 플로팅 액션 버튼 (FAB): "상담 신청" 전화 아이콘

**인페이지 네비게이션**
- 섹션별 "다음으로" 버튼 (플로팅)
- 스크롤 인디케이터
- 앵커 링크 자동 스크롤

**푸터 네비게이션**
- 회사 정보
- 법적 고지 링크
  - 개인정보 처리방침 (/privacy)
  - 이용약관 (/terms)

## 4. 페이지 계층 구조 (페이지 계층 구조)

```
/ (Depth 1 - 메인 랜딩페이지)
├── #hero (Depth 2 - Hero 섹션)
├── #problem (Depth 2 - 문제 제기 섹션)
├── #cause (Depth 2 - 원인 분석 섹션)
├── #solution (Depth 2 - 해결책 섹션)
├── #result (Depth 2 - 결과 증명 섹션)
└── #lead (Depth 2 - 리드 캡처 폼 섹션)

/success (Depth 1 - 성공 페이지)
/privacy (Depth 1 - 개인정보 처리방침)
/terms (Depth 1 - 이용약관)
```

## 5. 콘텐츠 구성 (콘텐츠 구성)

| 페이지/섹션 | 주요 콘텐츠 요소 |
|---|---|
| Hero | 헤드라인, 서브카피, CTA 버튼, 배경 이미지/영상 |
| 문제 제기 | 섹션 제목, 병원별 스크린샷 카드 2장 (오전/오후), 스크롤 가이드 |
| 원인 분석 | 섹션 제목, 3단 인포그래픽, 툴팁 아이콘, 설명 텍스트 |
| 해결책 | 섹션 제목, 4개 전략 카드 (아이콘, 제목, 설명), 호버 효과 |
| 결과 증명 | 섹션 제목, 애니메이션 그래프, KPI 카운트업 숫자, 성과 데이터 표 |
| 리드 폼 | 폼 제목, 입력 필드 4개, CTA 버튼, 개인정보 동의 체크박스 |
| 성공 페이지 | 성공 메시지, 후속 절차 안내, 추가 CTA |

## 6. 인터랙션 패턴 (인터랙션 패턴)

**스크롤 기반 인터랙션**
- 섹션별 fade-in 애니메이션
- 스크롤 진행률에 따른 네비게이션 하이라이트
- 패럴랙스 효과 (Hero 배경)

**호버 인터랙션**
- 카드 호버 시 그림자 증가 및 배경색 변화
- 버튼 호버 시 scale 확대 (1.05배)
- 툴팁 아이콘 호버 시 설명 팝업

**클릭 인터랙션**
- CTA 버튼 클릭 시 해당 섹션으로 부드러운 스크롤
- 폼 제출 시 로딩 스피너 표시
- 성공 시 체크 아이콘 애니메이션

**애니메이션 패턴**
- 그래프 데이터 시각화 (1.2초 EaseOut)
- 숫자 카운트업 애니메이션
- 슬라이더 자동 재생 (5초 간격)

**모바일 최적화**
- 터치 피드백 (버튼 tap 시 색상 변화)
- 스와이프 제스처 (슬라이더)
- 플로팅 액션 버튼 고정 위치

## 7. URL 구조 (URL 구조)

**메인 도메인 구조**
- 기본: `https://ad-recovery.example.com/`
- 병원별 맞춤: `https://ad-recovery.example.com/hospital/[병원ID]`

**URL 네이밍 규칙**
- 메인 페이지: `/`
- 성공 페이지: `/success`
- 개인정보 처리방침: `/privacy`
- 이용약관: `/terms`

**앵커 링크 구조**
- Hero: `/#hero`
- 문제 제기: `/#problem`
- 원인 분석: `/#cause`
- 해결책: `/#solution`
- 결과 증명: `/#result`
- 리드 폼: `/#lead`

**병원별 맞춤 URL**
- 패턴: `/hospital/[병원명-영문]`
- 예시: `/hospital/seoul-dental-clinic`
- 동적 생성: Google Sheets 데이터 기반

## 8. 컴포넌트 계층 구조 (컴포넌트 계층 구조)

**글로벌 컴포넌트**
- `Header`: 로고, 네비게이션, CTA 버튼
- `Footer`: 회사 정보, 법적 링크
- `FloatingActionButton`: 모바일 상담 신청 FAB
- `ScrollToNext`: 섹션별 다음 이동 버튼
- `Tooltip`: 전문 용어 설명 팝업

**섹션 컴포넌트**
- `HeroSection`: 메인 헤드라인, 서브카피, CTA
- `ProblemSection`: 문제 제기 컨테이너
- `CauseSection`: 원인 분석 컨테이너  
- `SolutionSection`: 해결책 전략 컨테이너
- `ResultSection`: 결과 증명 컨테이너
- `LeadFormSection`: 상담 신청 폼 컨테이너

**카드 컴포넌트**
- `ScreenshotCard`: 병원별 광고 스크린샷 카드
- `InfographicCard`: 원인 분석 3단 카드
- `FeatureCard`: 해결책 전략 카드 (아이콘 + 텍스트)
- `DataTableCard`: 결과 증명 성과 데이터 표

**폼 컴포넌트**
- `LeadCaptureForm`: 메인 상담 신청 폼
- `FormInput`: 입력 필드 (병원명, 담당자명, 연락처)
- `FormTextarea`: 상담 요청 내용 텍스트 영역
- `SubmitButton`: 상담 신청 제출 버튼
- `PrivacyCheckbox`: 개인정보 동의 체크박스

**데이터 시각화 컴포넌트**
- `AnimatedChart`: 결과 그래프 애니메이션
- `CountUpNumber`: KPI 숫자 카운트업
- `ProgressIndicator`: 스크롤 진행률 표시

**인터랙션 컴포넌트**
- `SmoothScroll`: 앵커 링크 부드러운 스크롤
- `LazyImage`: 지연 로딩 이미지
- `LoadingSpinner`: 폼 제출 로딩 표시

**유틸리티 컴포넌트**
- `Container`: 최대 너비 1200px 컨테이너
- `Section`: 섹션별 공통 래퍼
- `Spacer`: 섹션 간 여백 조정
- `ResponsiveGrid`: 반응형 그리드 레이아웃
