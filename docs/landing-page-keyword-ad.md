# 섹션 2: 문제 제기

## 배경: SVG 패턴

| 항목 | 내용 |

| 투명도 | 은은하게 (불안정함 표현) |

## 카피

### 타이틀

```
{{hospital_name}}의 현재 상황입니다
```

### 코멘트 (고정)

```
오전 예산 소진으로 오후 노출이 중단된 상태입니다
```


## 동적 데이터 가이드

### 데이터 소스: Google Sheets (3개 항목)

| 변수명 | 컬럼명 | 설명 | 필수 |
|--------|--------|------|------|
| {{hospital_name}} | hospital_name | 병원명 | ✅ |
| {{image_am}} | screenshot_am | 오전 스크린샷 URL (Cloudinary) | ✅ |
| {{image_pm}} | screenshot_pm | 오후 스크린샷 URL (Cloudinary) | ✅ |

### 변화 대비 사항

| 항목 | 현재 | 변화 가능성 | 대응 방안 |
|------|------|-------------|-----------|
| 스크린샷 개수 | 2장 (오전/오후) | 1장 또는 3장 이상 | 배열로 처리, 동적 렌더링 |
| 시간 라벨 | 오전 10:00 / 오후 14:00 | 다른 시간대 | 라벨도 데이터로 관리 |

### 확장 대비 스키마 (권장)

```json
{
  "screenshots": [
    { "time_label": "오전 10:00", "image_url": "https://..." },
    { "time_label": "오후 14:00", "image_url": "https://..." }
  ]
}
```

# 섹션 4: 해결 전략

## 유형: 공통

## 배경: SVG 패턴

| 항목 | 내용 |
|------|------|
| 성격 | 해결, 방향 제시 |
| 패턴 | 화살표/방향성 패턴 |
| 요소 | 우측/상단 방향 화살표, 방향선 |
| 색상 | 메인 컬러 연하게 또는 파란 계열 |
| 투명도 | 은은하게 (진행감 표현) |

## 카피

### 전략 1: 캠페인 그룹 분류 체계화

```
모든 키워드를 한 그룹에 넣으면 예산이 새어나갑니다.
목적별 분류가 효율의 시작입니다.
```

### 전략 2: 순위 전략

```
1위가 항상 정답은 아닙니다.
키워드별 최적 순위를 찾아 비용 대비 효과를 극대화합니다.
```

### 전략 3: 노출 시간 전략

```
하루 종일 균등하게, 또는 환자가 몰리는 시간대에 집중.
예산이 하루를 버틸 수 있도록 설계합니다.
```

### 전략 4: 자동 확장 검색 효율화

```
의도하지 않은 검색어에 광고비가 빠져나가고 있습니다.
확장 검색을 정교하게 다듬어 효율을 높입니다.
```
